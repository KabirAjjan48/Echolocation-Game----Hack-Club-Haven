Echolocation Game -- Hack Club Haven

This game utilizes a mechanic I call "echo."
The player must click "E" to echo, which increases the visibility area of the game.
The objective of this game is to get through the map without dying, unlock a gate, get through a maze, and get the treasure.
This game fits the theme of "Bounce Back", because echolocation is a process that animals like bats use to emit sound waves and listen to the echoes that bounce back from surrounding objects to navigate, hunt prey, and understand their environment.
